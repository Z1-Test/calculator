# Glossary

- **Accumulator**: Intermediate calculation value stored in the engine register.
- **Immediate Execution**: Sequential evaluation model where operations evaluate immediately upon entering the next operator.
- **Precision Normalization**: Scaled decimal rounding eliminating IEEE 754 floating-point inaccuracies.
